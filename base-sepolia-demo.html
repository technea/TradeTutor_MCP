Base Sepolia Wallet Lab

A testnet-only prototype for wallet-aware portfolio safety. It reads the connected wallet's Circle USDC balance, prepares a transfer proposal, checks basic policy rules, and asks for a separate wallet confirmation. No private keys are collected or stored.

TESTNET ONLY · Base Sepolia USDC has no monetary value. Never use this page for mainnet funds. Transactions are sent only after you press the final confirmation button and approve them in your wallet.

Safety policy

  • Only chain ID 84532 (Base Sepolia).
  • Only Circle's published Base Sepolia USDC contract.
  • Maximum transfer: 1 USDC per demo transaction.
  • Reject malformed, zero, and self-recipient addresses.
  • Read balance before proposal and again before sending.
  • Wallet must independently approve the transaction.

This is a prototype policy check, not a full smart-contract security audit or a guarantee that a recipient is trustworthy.
